# IPL Matches Data Analysis (Pandas)

A comprehensive data analysis project using **Pandas** to inspect, explore, and analyze historical Indian Premier League (IPL) match records from 2008 through 2024.

---

## 📌 Project Overview

This repository contains a Python notebook focused on exploratory data analysis of the IPL dataset. The project covers data loading, structural inspection, and quick previews of match data spanning over 1,000 matches.

Key highlights of the dataset:
- **Total Records:** 1,095 matches
- **Total Attributes:** 20 columns (including season, venue, teams, toss decisions, winners, result margins, and match officials)
- **Time Range:** 2007/08 – 2024 seasons
